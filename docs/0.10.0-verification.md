# 0.10.0 — 漫威专名词库扩充

日期：2026-10-28。包名 `org.watchersarchive.app`，versionName `0.10.0`，versionCode `16`。

## 结果与边界

英文助手由20条人工专名扩展为有来源的离线分片索引。生产资源有 **19,560条记录、25,812个归一化名称检索键、28,301个名称到记录映射**。其中947条具有实际含汉字的社区中文主名，18,613条明确未译；原有20条人工候选作为优先层保留，与批量数据存在重叠。

这些数字不是不同漫威人物总数，也不能称为完整中文漫威词库。类型包括角色17,202、组织168、团队6、地点400、物品229、待分类1,555；来源中也有与Marvel相关的现实人物和现实主题。重大事件、专有概念、近期新人物和中文地区译名的系统覆盖仍需继续核对。

两源输入为FiveThirtyEight历史角色数据16,376条和Wikidata范围导出4,213条。严格按单个完整Fandom页面一对一对照合并1,029对，保留来源ID和URL；多人、多页、不同类型、真人、宇宙或中文冲突不合并。有匹配但拒绝的11条另有原因记录。没有按名字相似给其他角色套用中文名，也未复制传记、剧情或图片。

FiveThirtyEight数据采用CC BY 4.0，角色快照为2014-08-24，不是当前全集。Wikidata为CC0社区数据，经第三方QLever镜像取得，不能据其LIVE标签保证实时同步，也不能称中文标签为授权出版社官译。完整证据见[词库说明](marvel-reading-glossary.md)、[历史数据来源](marvel-fivethirtyeight-source.md)、[Wikidata来源](marvel-wikidata-source.md)及[精确对照规则](marvel-glossary-source-merge.md)。

## 应用行为

- 安装后离线查名，不需要电脑IP、账户、API密钥或上传漫画页。
- 匹配当前OCR行中的完整名称、代号和身份别名，最多5词／窗口、64个窗口／查询、3个显示候选；不跨行猜角色。
- 人工首选“镭射眼”等继续优先；普通词义保留，中文摘要只统计实际有中文的候选，英文回退值不冒充译名。纯英文zh标签可检索，但不作为中文别名展示。
- 拒绝将A、It、One等常见功能词单独送入扩展实体查询。跨宇宙和MCU候选保留独立ID，显示排序不等于身份确认。
- 查询在IO线程按需打开分片，别名／实体各最多4个LRU分片，分片编码／解码上限1MiB。生产512个分片压缩总计1,298,748字节，最大解压分片57,136字节；本次无别名截断。
- 索引分片校验长度、gzip、SHA-256、结构和桶位置。损坏资源给出明确提示，同时保留基础词表和普通词典。
- 查询循环和读取块检查协程取消；索引关闭采用非阻塞锁，正在读取的任务在finally清理，避免Compose销毁等待新词库IO锁。
- 设置的“关于与版本”增加词库署名及来源／许可链接；原有紧凑卡片避让、发音与展开交互保持可用，没有生词本。

本轮未修改500,000,000字节漫画临时缓存、Range／ETag、CRC、页面租约、下载正文、书架与个人书名、进度、书签或笔记存储。
