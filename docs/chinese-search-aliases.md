# 中文检索别名与官方译名证据边界

检查日期：2026-10-27。本轮新增的是一个小规模、可追溯分类的检索词表，**没有核验成功的中文官方漫画书名条目**。目前 15 条均标记 `COMMON`，不能在界面或报告中称为“官译已接入”或“完整中文书目”。

中文别名把查询导向已有英文目录候选，不代表候选文件是中文版，也不代表它是某本中文出版物的同一发行版本。角色/团队别名与漫画书名分开存储；电影名称不能作为漫画书名的授权出版证据。

## 查询行为与测试

`CatalogSearchAliases.expandedTerms(query)` 对输入作 NFKC 归一化，然后按当前位置最长已知别名替换，例如：

- `蜘蛛侠 2020 #1` → `Spider-Man 2020 #1`；年份与期号保持不变。
- `神奇蜘蛛侠2018` → `Amazing Spider-Man 2018`，不会先替换较短的“蜘蛛侠”。
- `蜘蛛侠第１期` → `Spider-Man #1`；`内战第2卷` → `Civil War Vol. 2`。结构标记仅作字面查询线索，不确认其发行版身份。
- 显式收录的繁体形式可以命中；没有用全量简繁转换推断未经核实的地区译名。
- 两字及以上且能匹配已知名称开头的输入（如“蜘蛛”“复仇”）可作受限主题扩展，最多返回三个不同英文词。
- `无限战争` 不会被当作 `无限手套`；未知中文不猜译。`未知蜘蛛侠` 会保留“未知”，不会悄悄丢掉限定词。

该模块不修改漫画标题，不合并来源记录，不给结果附加“中文正文”标签。将来 UI 若展示别名出处，应准确标注“常用检索别名”或经逐条证据确认的地区出版译名。

使用独立 Kotlin 2.0.21 编译器和 JUnit4 实际执行 `CatalogSearchAliasesTest`：**6 项通过**（`OK (6 tests)`），没有运行共享 Gradle。测试覆盖最长名称、年份/期号、繁体与全角形式、受限前缀、未知限定词与证据级别；Android 集成与完整套件由父任务统一验证。
