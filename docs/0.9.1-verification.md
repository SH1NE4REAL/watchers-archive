# 0.9.1 — word-card placement and Marvel-name candidates

Date: 2026-10-28. Package `org.watchersarchive.app`, versionName `0.9.1`, versionCode `15`.

## Selected text stays visible

The previous reader anchored every dictionary card at the bottom with up to 330dp height. The reader now reports its actual Fit/zoom/pan geometry through a side-effect callback; the card uses the selected word's screen rectangle in the unpadded reader viewport. Updates are requested only when the assistant is active.

The default card is a compact summary, at most 160dp or 25% of the viewport height. It shows the selected text, a primary Chinese meaning or labelled Marvel-name candidate, speech, expand, move and close actions. Expanded details show phonetics, parts of speech, ordinary meanings, the OCR line, optional model tools and attribution; height is capped at 360dp or 45% of usable space.

Automatic placement chooses the side with usable room, preserves a 12dp selection gap and avoids status/cutout/navigation areas. Where possible it reduces height before covering selected text. “上移 / 下移” lets the user choose the other edge; “自动” restores geometry-based placement. The same selection retains expansion/manual preferences across asynchronous lookup completion, and a new selection starts compact and automatic. Pinch/zoom can update automatic placement. Manual choice intentionally takes precedence, even if it overlaps a word.

This is an overlay, so it can still cover another unselected part of the image. A very large selected box or extremely small viewport may leave neither side large enough; the placement result reports that condition rather than hiding the card or claiming every pixel is unobstructed. No free-drag interaction or split-screen image resize is introduced. The old permanent Ready-state instruction was removed so it does not keep covering bottom-page dialogue.

## Names and ordinary dictionary senses

The provider now attaches a distinct `MarvelReadingGlossary` result to its ordinary dictionary entry. `Cyclops` and `Scott Summers` can suggest **镭射眼**, while the original ordinary definition remains available in expanded details. `Storm`, `Thing`, `Vision`, `Beast` and other ambiguous words are candidates, not silently rewritten definitions. Normal English spelling, OCR text, image coordinates and page identity remain unchanged.

The first table contains **20 entities** spanning characters, teams, organisations and places. Known complete names and aliases use bounded same-line longest matching; function words do not inherit nearby names. No OCR typo guessing or story inference is added. The current comic title may provide a weak X-Men hint, which never confirms a character's identity. Matching runs locally without an account, cloud model or page upload.

Chinese **镭射眼** is recorded as the project user's preferred name. Other Chinese names are COMMON labels; this release has not established licensed Chinese publisher/ISBN title evidence. English Marvel reference links and their access status are documented separately from Chinese-name evidence. The normal Cyclops page request returned HTTP403 and was not bypassed. See [marvel-reading-glossary.md](marvel-reading-glossary.md) for the full scope and matching limitations. Product cards show short evidence labels rather than internal HTTP or data-audit notes.
