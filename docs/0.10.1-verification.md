# 0.10.1 — 阅读器指定页码跳转

日期：2026-10-29。包名 `org.watchersarchive.app`，versionName `0.10.1`，versionCode `17`。

## 使用方式

轻点漫画画面显示阅读控件，点击顶部“第…页 · 跳页”，输入1到总页数之间的页码，点“跳转”或数字键盘的“完成”。打开时自动聚焦并选中当前页码，方便直接替换。

空白、0、负数、小数、非数字、整数溢出和超总页数输入会提示错误，不发起读取。输入不会通过删除符号被悄悄改成另一页。取消对话框或选择当前页不重新加载，保留当前图片、缩放和租约。

有效跨页跳转复用原有 `load(index)`，总页数来自当前ReaderSession，显示页码与内部索引之间只做减1转换。加载期间禁用页码按钮和前后翻页。读取失败保留原页面，现有“重试”继续读取指定目标；成功后沿用原有进度持久化、书签、预读和英文助手切页清理流程。

## 页面租约修复

新增的同步ReaderSession测试发现：原先 `DisposableEffect(page)` 在composition求key、稍后安装effect时再次读可变page，两次值可能不同。初始key为null而页面已经同步返回时，旧effect会错捕第一页，下一次重组可能提前释放正在显示页的租约。

修复把 `val displayedPage = page` 放在effect外，保证key与回调捕获同一个composition快照。当前页保持租约，直到新页替换或阅读器退出才释放。证据来自主机UI测试，不称为已在手机或真实HTTP上复现。
