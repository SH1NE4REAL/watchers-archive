# 英文助手的漫威专名候选

日期：2026-10-28。本次是一个小规模、可离线使用的专名词表，与普通 ECDICT 释义并列，不是完整漫威知识库，也不进行剧情推断。

## 本轮覆盖

`MarvelReadingGlossary` 收录 20 个主题：Cyclops、Storm、Beast、Thing、Vision、Angel、Iceman、Professor X、Magneto、Wolverine、Colossus、Nightcrawler、Scarlet Witch、Iron Man、Spider-Man，以及 X-Men、S.H.I.E.L.D.、Hydra、Wakanda、Asgard。类型分为角色、团队、组织和地点；已知英文全名作为明确别名，例如 Scott Summers 对应 Cyclops。

Cyclops 的中文“镭射眼”由用户明确指定，证据级别为 `USER_PREFERRED`。其余中文名称标记为 `COMMON`。**本轮没有授权中文出版方／ISBN 证据，因此不称为官方汉化或官译。** 地区译名、代号继承和多宇宙身份仍需逐条补证；本模块不把同一代号强行对应到所有版本中的同一人物。

各条目保留英文标准名、英文别名、中文显示名、类型、英文资料入口、中文证据级别、歧义说明和检查日期。Marvel 英文 URL 不证明中文名获得官方授权；组织、团队和地点使用官方站内检索入口，不冒充已抓取的实体详情。

## 正常来源检查

对 [Marvel Cyclops / Scott Summers 英文角色页](https://www.marvel.com/characters/cyclops-scott-summers) 实际执行了一次普通 HTTPS GET，本环境返回 **HTTP403**，已停止，没有绕过验证或读取隐藏接口。不能声称本轮读取并核实了该页面正文。词表保留这个英文资料链接供后续核对；用户指定中文名与该访问结果分开记录。

没有把电影中文片名、论坛说法、GetComics 文件名或普通英汉词典义项直接升级为官方中文漫画译名，也没有批量抓取、付费 API 调用或漫画页面上传。

## 匹配与歧义

- 查询只接受当前页面已有的词语或由阅读器创建的有效连续选区。英文做大小写、全半角、标点和已知缩略形式归一化；漫画全大写不增加可信度。
- 可检查所点单词所在 OCR 行，寻找包含这个单词的最长已注册名称，例如点 `Summers` 也能得到 `Scott Summers` 候选。每个名称最多跨 5 个 OCR 词，不跨行、不跨气泡猜测。
- 单独点击 `the/a/an/and/of/to/in/at` 等功能词时不扩大为周边专名，避免在 `The Thing` 中点 `The` 却得到角色解释；显式选中完整 `The Thing` 仍能匹配。
- 词组选择可以返回多个已注册名称，最多 3 项。命中按实体 ID 去重；保留匹配的原文，完全不改 OCR 结果、页身份或图片坐标。
- `Storm`、`Thing`、`Vision`、`Beast`、`Angel` 等仍可能是普通英语词。所有匹配都作为“漫威专名候选”；普通词义必须保留。书名含 X-Men 只提供弱提示，不能证明当前句子一定指某个角色。
- `something` 不会因为含 `thing` 命中石头人；`Cycl0ps` 等 OCR 错字本轮不猜译。未来若增加形近容错，需要明确标低可信候选，不能静默修改原文。

当前精确词表和规则不需要网络模型、账户或上传页面。复杂同名角色、版本关系、人物指代和剧情级语境消歧属于后续工作，不能由当前词表推断。
