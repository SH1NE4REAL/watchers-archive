## Remaining boundaries

RAR5, solid, encrypted, split and PPM-compressed archives are rejected. The PPM allocator is blocked before any archive-controlled allocation. Normal LZ RAR4 is supported through pinned Junrar7.5.5, with the full UnRAR license packaged in APK assets.

RAR4 has no ZIP central directory: first indexing can be slow on a high-latency source. A bounded 512KiB header / 1.5MiB page-block cache reuses validated identities across the prepare/open boundary, and a validated first page is committed through CacheManager for reuse. No whole-file fallback is used.

Cover bitmap memory is bounded at 16MiB. Disk covers share the fixed 500,000,000-byte budget with pages. First network loads still depend on the source connection; cached re-entry does not wait for another request.

SAF import reads only the explicitly selected seekable `content://` document and persists its read permission. No full-file copy or broad storage permission is added. Physical-phone SAF behavior and end-user visual acceptance remain unverified.

Removing a shelf item only changes memberships. Source files, source records, progress, bookmarks and notes remain intact; regression tests reopen the persistent stores to verify this.
