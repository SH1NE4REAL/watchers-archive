# 0.6.1 — phone-only networking and explicit mobile-data downloads

Date: 2026-10-27. versionName 0.6.1 / versionCode 9.

The catalogue and public-file resolver use the Android device's own network to access GetComics and its public file hosts. Completed downloads use private phone storage. No personal PC backend, USB forwarding or home LAN membership is required for those paths. The current LAN APK URL distributes the installer; synthetic test comics remain development fixtures rather than production content.

This release makes “允许使用手机流量” explicit in both the first-download and resume confirmation. It defaults off, preserving the existing non-metered-network policy; enabling it selects WorkManager CONNECTED so metered Wi-Fi and cellular networks are eligible. Existing queued tasks retain their chosen policy: pause and resume with the new choice to change it. This fixes the previous management-screen resume action, which always forced wifiOnly=true.

WorkManager's UNMETERED means an unmetered network, usually Wi-Fi; it is not a guarantee of a physical Wi-Fi transport. CONNECTED permits cellular but successful delivery still depends on device network/storage/OS scheduling and source availability. No source authorization bypass or unrestricted-host promise is introduced.

Real comics missing their explicit source URL now fail before issuing a request; only marked synthetic test comics can use the configurable fixture base address. This prevents a broken real record from falling back to a PC test server. Strong ETag, Range validation, cancellation, offline leases, the 500,000,000-byte temporary budget and persistent data remain protected.

## Quality-first Chinese reading

The user selected translation quality as the priority and is willing to consider online services. A public cloud translation service can be contacted by the phone; it does not require the user's PC. Choosing a service, account/credentials, price/quotas and what data is uploaded remains necessary before real cloud calls. This release makes no paid requests and does not implement a cloud translator or image-level Chinese overlay. The current model's quality is not improved by merely changing its display location.

The reviewed provider options, official API evidence and integration contract are in [quality-chinese-reading-design.md](quality-chinese-reading-design.md).
