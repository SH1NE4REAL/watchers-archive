# 观察者漫格当前项目状态报告

日期：2026-10-27。当前 APK：0.7.1，versionCode 11。

## 已完成

### 产品界面

- 底部导航为“观察者书库 / 我的书架 / 设置”。
- 观察者书库固定包含搜索框和“最近更新 / 大事件专题 / 官方推荐”三个栏目。
- 大事件使用带封面的纵向卡片；书架使用封面网格和可删除、移动的分类。
- 设置中包含连续翻页加速、阅读时屏幕常亮、默认允许流量下载、离线下载管理、存储管理和关于版本。
- 临时缓存容量、清理按钮、传输字节、缓存命中、调试日志等技术细节已从阅读主界面收起。缓存详情仅在“设置 → 存储管理”中显示。
- 用户提供的红白头像已作为 Android 应用图标，生成 mdpi、hdpi、xhdpi、xxhdpi、xxxhdpi 资源，并在 Manifest 中同时设置普通和圆形图标。

### 阅读、缓存和离线下载

- 远程 CBZ/ZIP64 按页读取，保留 Range 206、Content-Range、强 ETag、CRC、解压大小、像素数和取消校验。
- 阅读预读最多两个后续页面；已缓存页面回翻时不等待无关的后台网络任务。
- 临时页/封面缓存硬上限为 500,000,000 字节，空间满后按 LRU 清理未使用内容；阅读进度、书签、笔记和目录独立保存。
- 整本离线下载保存在手机 App 专用存储，不进入 500 MB 临时缓存。支持 Wi-Fi 或用户明确允许的手机流量、暂停、继续、断点恢复、删除和来源版本校验。
- 整本下载采用流式 Range 窗口，默认最多 16 MiB、内存缓冲不超过 64 KiB；来源只接受 4 MiB 范围时有限回退。窗口校验完成后才写入持久断点。
- 已下载文件在来源网络不可用时可以从手机本地读取；删除下载不会删除书架、进度、书签和笔记。

### 目录和搜索

- GetComics 文章元数据、封面、来源文章和候选文件保持分离。
- 搜索支持大小写、全半角、空格、连字符和有限英文拼写模糊匹配。
- 搜索严格保留年份和期号，避免 `#1` 命中 `#10`；不同来源、文章和版本不会只按标题合并。
- 已取得的目录可以离线参与搜索；在线部分失败时保留本地结果并提示结果可能不完整。
- 已加入 15 组常用中文检索别名，例如“内战 → Civil War”“X 战警 → X-Men”。这些别名全部标为 `COMMON`，没有冒充官方中文出版书名。

## 当前待处理问题

### 中文阅读

当前仍是设备端 OCR 和机器翻译对照面板，没有实现气泡内中文覆盖，也没有专业汉化排版。联网高质量翻译方案已经整理，但尚未接入 DeepL、Qwen-MT 或其他付费服务，也没有配置用户 API Key。现阶段看英文原版、导入可信中文版本，或后续增加选区查词，是风险较低的选择。

### 真实手机验收

没有完成新的连接设备 instrumentation、蜂窝网络下载测速、锁屏后台下载、OEM 电池限制和真实超大漫画整本下载验收。主机测试证明算法和边界，不代表每种手机网络都能访问来源。

### 来源可用性

GetComics 不是完整官方目录，也不是所有文章都提供授权、稳定或可公开程序访问的文件。来源需要登录、验证码、付费或不支持 Range 时，App 会拒绝静默整本下载。

X-Men by Jonathan Hickman Omnibus (2022) 的 Pixeldrain 页面显示免费传输额度为 6.00 GB、当天已使用 6.65 GB。这个限制由 Pixeldrain 服务器控制，不能由 App 或缓存设置解决；需要等待来源额度重置、使用正常授权账户，或寻找明确允许访问的其他来源。本次没有下载漫画正文。

## 后续优化建议

1. 先在一部来源稳定、支持 Range 和强 ETag 的中等大小漫画上做手机 Wi-Fi/流量验收，再评估实际翻页和整本下载速度。
2. 为来源失败增加更细的状态，例如今日额度耗尽、来源不可达、需要用户操作和暂时限流，避免用户看到笼统错误。
3. 如果继续做中文，先实现“选区查词 / 单句翻译”，再做带 OCR 坐标的可逆中文覆盖；整本预译应是用户主动操作并显示预计流量和存储。
4. 增加阅读方向、横竖屏锁定、书架/进度导出和备份。当前没有为尚未实现的功能放置空开关。
5. 对 GetComics 更新服务增加低频调度、来源发布时间与发现时间区分，以及无法匹配系列/卷次/期号的待确认列表。
