# 英文助手的词典数据、模型与验证边界

核实日期：2026-10-28。本版英文助手使用随 APK 安装的 **ECDICT 离线英汉词典**，不依赖用户电脑、API Key 或在线词典连通性。单词释义与音标来自词典数据；发音由 Android 的文字转语音服务处理，语境参考则属于单独的设备端机器翻译。

## 数据来源及许可

- 官方项目：[skywind3000/ECDICT](https://github.com/skywind3000/ECDICT)。
- 原始词库：[ecdict.csv](https://github.com/skywind3000/ECDICT/blob/master/ecdict.csv)，实际获取长度 **66,009,548 字节**。
- 核实的 Git blob SHA-1：`0e527e22e0e0d22f012b0ed251a8dddd5891773b`。
- 原文件 SHA-256：`d1ecbdf9ee2b920afb6f430ca6b6bb9f559588cf0dff86e04bd255f9390843cc`。
- 实际读取的上游 [LICENSE](https://github.com/skywind3000/ECDICT/blob/master/LICENSE) 为 **MIT License，Copyright (c) 2025 Linwei**。完整许可文本保存在 APK 的 `english-dictionary/LICENSE.txt`，仓库也保留此文件。
- 上游 README 将 CSV 描述为基础版本，而非其另行提供的全部增强词库。本项目没有下载增强版或声称拥有完整英语词汇覆盖。

原 CSV 不提交到仓库，而是保留在忽略的 `.tools/english-dictionary/`。生成工具 `tools/build_english_dictionary.py` 先核对原文件长度与官方 Git blob，再按稳定规则生成 256 个 SHA-256 首字节分片。词库由源码衍生，原文字义、音标、词性和英文定义均不由模型补写；过长字段按显式预算截断，大小写/全半角重复键统一后保留有效中文条目。单边缩略形式 `'cause`、`'em` 的撇号不会被当作普通引号删除。

分片实际采用 **gzip 编码、`.dict` 后缀**。Android Gradle 资源合并器会自动解压 `.gz` 文件并删掉该后缀，因此不能直接以 `.json.gz` 命名后再在运行时调用 `GZIPInputStream`。本版使用中性 `.dict` 文件名，并由应用明确解码；清单逐项记录 APK 内应存在的名称。

实际构建结果：

- 原始 CSV：770,611 行；构建后 **769,778 个不同检索键**；跳过 3 个无效/超长输入，其他数量差异来自规范化重复键。
- 256 个 gzip 数据分片共 **32,681,942 字节**。
- 加上清单和许可共 **32,740,260 字节**。
- 最大单个解压分片 **317,333 字节**；生成清单逐项记录字节数、条目数及 SHA-256。
- 原始数据有 218,065 行提供音标，部分短语没有音标或词性。这些缺项不会被编造成词典事实。

应用一次仅解码需要的分片，最多保留 4 个分片和 128 个查询结果，未把整个词典载入内存。读取设置了 8MiB 解压/8,192 条目单分片硬边界。词典随 APK 安装，因此属于应用资源占用，不属于可被自动 LRU 淘汰的漫画临时缓存，也不会成为个人生词记录。

重新生成示例：

```powershell
python tools/build_english_dictionary.py .tools/english-dictionary/ecdict.csv --license .tools/english-dictionary/LICENSE
```

## 中文释义和语境参考的区别

普通词或已收录短语直接返回离线中文、词性、音标和可用的英文定义，不下载语言模型。例如 `hero` 实际词条包含“英雄、超越常人者、男主角”；`slow down` 实际词条包含“(使)慢下来”，但该短语的上游条目没有音标和词性。

若用户希望查看原句参考译文或词库未收录短语的机器译义，需要在卡片中**明确选择下载模型**。模型由 Google ML Kit 设备端翻译提供，可选择仅 Wi-Fi 或允许手机网络下载。打开助手或查普通词不会自动下载模型。已有模型时，当前 OCR 原句留在手机上处理；本版不把漫画图片、上下文或点击词语发给公共词典服务。

卡片会区分词典释义、原句和机器参考译文。普通字典列出的多个义项不会被假装成已按漫画情节完成消歧；艺术字体、人名、俚语和 OCR 错字仍可能查不到或误译。模型下载、真实 OCR 结果、翻译质量以及系统语音是否已安装英文声音，仍需在用户手机上实际确认。

## 在线候选调研结果

正常请求 `dictionaryapi.dev` 首页、公开 `/hero` 和 `/slow%20down` API 在本次环境均返回 HTTP403。其官方 GitHub README 可正常读取，但 API 服务没有成功返回词条，不能把它当作手机上稳定可用的唯一词典。本版因此不默认调用该服务，也没有内嵌其服务器代码或未知来源词条。

## 实际测试范围

`PublicEnglishDictionaryProviderTest` 检查本地普通词、短语、IPA 缺项、来源标注、纯本机上下文翻译注入、未知词诚实回退、显式模型下载及网络选择、关闭、缓存、缩略词规范化和损坏资源提示。实际资源集成测试要求清单对应已核实源 blob、超过十万条，并从打包资源查出 `hero` 和 `slow down` 的中文，检查完整 MIT 许可存在。测试中的翻译引擎是可控替身，不声称已验证 Google 模型下载或真实中文质量。
