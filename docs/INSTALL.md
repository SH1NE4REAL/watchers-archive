# 观察者漫格 Android 安装说明

## 从 GitHub 下载

在手机浏览器打开仓库中的 [watchers-archive-0.7.1-icon.apk](../downloads/watchers-archive-0.7.1-icon.apk)，点击下载。也可以在 GitHub 项目首页打开 `downloads/` 目录后点击 APK 文件，再点击 Download raw。

## 安装

1. 下载完成后点击 APK 文件。
2. 如果系统提示禁止安装未知来源，只为当前浏览器开启“允许安装未知应用”。
3. 返回安装界面，选择安装或更新。
4. 安装完成后关闭浏览器的“允许安装未知应用”权限。

更新安装会保留 App 内的书架、阅读进度、书签和设置。卸载 App 或清除应用数据会删除 App 专用存储中的整本离线漫画和临时缓存。

## 使用条件

- 不需要电脑、ADB、USB 调试、局域网 IP 或测试服务器。
- 目录、封面和在线漫画来源使用安装手机自身的 Wi-Fi 或移动网络。
- 下载整本漫画时，详情页可以明确选择是否允许手机流量；默认遵循设置中的网络选项。
- Android 13 及以上建议允许通知权限，这样能看到后台下载进度。
- 设备需要有足够的可用存储空间。整本离线漫画独立保存，不受 500 MB 临时阅读缓存上限限制。
- 某个来源的登录、验证码、免费流量额度或地区限制由来源网站决定，App 不会绕过这些限制。
