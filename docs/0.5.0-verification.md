# 0.5.0 — page turns, Chinese comparison and search navigation

Date: 2026-10-27. APK versionCode 7 / versionName 0.5.0.

## Changes

- A serial rolling window previews up to two upcoming pages. Per-page eligibility remains at most 8MiB compressed and 16MiB decompressed; total window output is limited to 24MiB. The second in-flight page is retained as the window advances. Previewing does not create additional Bitmaps or write reading progress, and all page bytes use the original CacheManager budget.
- A foreground cache hit acquires a page lease and decodes directly, without waiting behind unrelated slow preview HTTP headers or the archive mutex. An uncached foreground request still coordinates cancellation and serial archive access.
- Android back and the search field's back/clear actions return to recommendations. Returning from an article preserves query, results and list position without repeating a completed search. Only the small query/scroll state enters the saved-state Bundle.
- The large app title is replaced by original red comic-panel and lightning decoration. There is no official Marvel logo or endorsement claim.
- The fullscreen reader toolbar has an optional “译文” action. Opening the panel checks the local model; OCR and model download require an explicit button press. The first download uses Wi-Fi by default. Latin OCR and English-to-Chinese translation run on the device; the panel shows selectable paired text with Google translation attribution. Original page artwork is unchanged.
- Translation processing has block, character, input-pixel and memory-cache limits. Keys include comic identity, strong ETag/page identity and engine version. Dismissing or changing page cancels page processing and closes clients. A model download managed by the SDK can continue after dismissal. Language models occupy separate SDK-managed storage; the panel explains the approximately 30MB model download before confirmation. Clear-cache also clears translated text from process memory.

## Translation limits and official references

Translation controller and Compose tests use a fake engine; actual SDK symbols and native libraries are compiled and packaged. The actual model download, OCR, translation output and phone memory have not been tested here. Google model delivery can fail on a particular network or device; a successful model download is necessary before offline translation is available.

Recognition uses the existing bounded display Bitmap. Small lettering, artistic fonts, names, speech-bubble order and layout may be misrecognized. This release provides a text companion, not translated lettering inside the artwork. Machine translation is not an official Chinese edition. A verified existing Chinese archive imported through the system document picker remains an option for original typesetting.

- [On-device Translation on Android](https://developers.google.cn/ml-kit/language/translation/android)
- [Supported translation languages](https://developers.google.cn/ml-kit/language/translation/translation-language-support)

The ML Kit usage page was accessible and points to Cloud Translation attribution rules. The linked Cloud documentation timed out on this validation network, so the exact current badge/layout requirements could not be independently checked. This personal prototype displays linked Google Translate attribution; review the linked Cloud rules and approved assets before public distribution.

Two-page preview improves already fetched page turns and reduces avoidable waits. A slow source, an archive's initial index, a page above preview limits or turning faster than the connection can fetch still causes a visible load. No fixed phone latency or complete-source availability is promised.
