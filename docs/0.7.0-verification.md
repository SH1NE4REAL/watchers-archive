# 0.7.0 — Watcher's Library and consolidated settings

Date: 2026-10-27. versionName 0.7.0 / versionCode 10.

## Library and navigation

- Bottom destinations are now “观察者书库 / 我的书架 / 设置”. The library uses an original shield icon, red selected states and a compact pale-red decorative bar with original shield, web, star and lightning motifs. No publisher logo or downloaded character artwork is used.
- The library's search and three equal-width buttons stay above the scrolling content. “最近更新” is the default. “大事件专题” retains the full-width vertical event cover cards. “官方推荐” contains the saved official guides and characters, with an accurately labelled Marvel official-guide link when no snapshot is available.
- Search still uses the connected source catalogue's actual coverage. It does not claim a complete Marvel catalogue. Back from search restores the selected section; returning from a detail retains query, results and scroll without another identical request. Saved section state accepts the older three-field Bundle format.

## Settings and storage

- Settings does not display cache figures or cleaning actions on its main screen. They are inside “存储管理”, which reads the cache snapshot only when opened. The debug-only fixture controls remain hidden behind the version label's long press.
- Reading settings control real read-ahead and optional keep-screen-on. The screen flag applies only while the reader is active and is restored on exit. The default remains off.
- The persistent “默认允许流量下载” setting supplies the initial choice for new and resumed downloads. Individual confirmation can override that choice; existing queued tasks keep their previous constraints. Download management and about/version are available in settings.
- The temporary disk-cache cap remains **500,000,000 bytes**, with the existing bounded reservation/LRU/lease rules. At allocation time, eligible least-recently-read content is reclaimed. If sufficient unpinned space cannot be reclaimed, a new cache write is refused. No periodic full-book deletion or larger capacity is introduced.
- Explicit full downloads remain in private phone storage independently of temporary pages/covers. Clearing temporary content leaves downloaded archives, catalogue, shelves, progress, bookmarks and notes intact. Uninstalling the app or clearing its application data removes its private storage; this release does not add export/backup.

A larger disk cache would retain more pages/covers, reduce repeat network/decompression work and help switching among online books. It does not increase source bandwidth, remove the first cold request or automatically enlarge bitmap memory. Already downloaded books obtain less benefit. The current cap is retained in line with the request.
