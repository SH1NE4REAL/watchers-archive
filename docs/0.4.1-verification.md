# 0.4.1 — folder deletion and page latency

Date: 2026-10-27. APK versionCode 6 / versionName 0.4.1.

## Implemented

- Long-press a category cover or open its header action to delete it. Confirmation states that members return to the default shelf. Deletion is an atomic membership update; files, metadata, progress, bookmarks and notes remain intact. Default/all containers are protected.
- RAR4 page reads adapt from 64KiB up to 1MiB, constrained by the source range limit and page transfer budget. Header blocks remain small. No complete archive download is introduced.
- One-page read-ahead runs while the current page is displayed. Only pages within the 8MiB packed / 16MiB unpacked preview bounds are eligible. Preview output is CRC-checked, stored through CacheManager and does not decode a second Bitmap or update progress.
- Foreground reads reuse matching in-flight preview work; unrelated preview work is cancelled before a foreground source read. The session closes its preview scope and HTTP reads on exit.
- The 500,000,000-byte budget still applies. Preview entries inherit the last actual reading timestamp, and old unpinned pages of a very long active comic can be evicted while its displayed page remains pinned.
- Settings contains an enabled-by-default read-ahead switch. Disabling it reduces speculative traffic. Large Range blocks can read bounded adjacent bytes; this is a latency/bandwidth tradeoff, not a free network speed increase.

## Actual verification

- App host/runtime tests: **71 passed, 0 failures**. Includes category deletion UI/persistence/rollback, prefetch priority/cancellation, no premature progress update, warmed next-page cache hit with zero extra HTTP requests, LRU timestamp protection and budget enforcement.
- Core tests: **45 passed** (Reader18 / Local5 / RAR13 / Cache9), `CORE_TESTS_PASS`.
- APK assembly and instrumentation source compilation passed. No physical-phone or connected instrumentation claim is made.
- Generated 2.36MB RAR4-page fixture: 37 requests / 2,424,832 bytes with the prior 64KiB cap versus 3 requests / 3,145,728 bytes with the adaptive 1MiB cap. Round trips fall by about 92%, with 720,896 additional bounded adjacent bytes. An 8ms/read host simulation is only a simulation, not a phone timing promise.

## Chinese content options (not implemented in this APK)

The source pages are scanned images in their original language. UI localization cannot translate their lettering. Importing an existing Chinese CBZ/RAR4 edition gives the best typography and translation quality; GetComics does not guarantee such an edition.

A feasible first machine-translation feature is an explicit “Translate this page” action: bundled Latin OCR, downloaded on-device English/Chinese translation model, then paired original/Chinese text. Original images stay unchanged, translation does not block turning pages, and names/artistic fonts/reading order require corrections. A language model must be downloaded successfully before offline translation can be promised; official documentation describes models at about the 30MB scale. Full speech-bubble removal and relettering is a separate, larger feature.
